
# AI-Enhanced Student Portal Prototype for Van Hien University

This repository contains the source code for a prototype of an AI-enhanced student portal for Van Hien University (VHUU). This project is part of a scientific research initiative focused on leveraging AI to optimize school operations. The prototype features a complete redesign of the student dashboard with a modern UI, integrated AI assistance, and other essential student information modules.

## Features

-   **Modern UI/UX:** A visually appealing interface built with Glassmorphism, soft gradients, and smooth animations powered by Framer Motion.
-   **Responsive Design:** Fully responsive layout that works seamlessly on desktops, tablets, and mobile devices.
-   **Dark Mode:** A beautiful, easy-on-the-eyes dark mode that can be toggled instantly.
-   **Interactive Dashboard Sections:**
    -   Personal Information
    -   Academic Results with charts (via Recharts)
    -   Weekly Schedule / Calendar
    -   Course Registration Form
    -   Settings Panel
-   **Integrated AI Assistant:** A multi-functional AI assistant with dedicated modules for:
    -   Personalized Learning Support
    -   Emotional and Mental Health Support
    -   Administrative Procedure Automation
    -   Data Transparency and Security
-   **Simulated AI Chat:** Interactive chat modals for each AI assistant module to demonstrate the user interaction flow.

## Tech Stack

-   **Frontend:** React 18 with TypeScript
-   **Styling:** Tailwind CSS
-   **Animations:** Framer Motion
-   **Charting:** Recharts
-   **Icons:** Lucide React

## Installation & Setup

To run this project locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/vhuu-ai-portal.git
    cd vhuu-ai-portal
    ```

2.  **Install dependencies:**
    You'll need Node.js and npm (or yarn) installed.
    ```bash
    npm install
    ```

3.  **Set up environment variables:**
    This project does not require any environment variables to run the prototype.

4.  **Run the development server:**
    ```bash
    npm start
    ```
    The application will be available at `http://localhost:3000`.
